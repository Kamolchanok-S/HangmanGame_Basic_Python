# HangmanGame_Basic_Python
# 🕹️ Terminal Hangman Game with Hints

A simple terminal-based Hangman-style word guessing game in Python that gives players a hint for each word. Great for learning Python basics like loops, conditionals, and string manipulation.

## 📦 Features

- Random word selection from a diverse vocabulary set
- Hints provided for each word to aid guessing
- Letter-by-letter guessing with instant feedback
- Option to replay the game after winning

## 📁 File Structure

- `game.py` — Main game logic, runs the game loop and handles user input.
- `word_h.py` — Dictionary of words and their hints.

## ▶️ How to Run

1. Make sure you have Python 3 installed.
2. Clone this repo or download the files.
3. Open a terminal in the project directory.
4. Run the game:
   ```bash
   python game.py
